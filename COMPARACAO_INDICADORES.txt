┌────────────────────────────────────────────────────────────────────────────┐
│ ANTES - Sistema com ADX e Bollinger Bands                                 │
├────────────────────────────────────────────────────────────────────────────┤

│   ✓ ADX                      - Força da tendência          ❌ REMOVIDO    │
│   ✓ Bollinger Bands          - Volatilidade/posição        ❌ REMOVIDO    │
│   ✓ ATR                      - Volatilidade                               │
│   ✓ Volume                   - Confirmação                                │
│                                                                            │
│ Estrutura de Estados:                                                      │
│   3 (MA) × 4 (RSI) × 2 (ADX) × 3 (BB) × 2 (Vol) × 2 (Vlu) × 2 (Time)     │
│   = 576 ESTADOS TOTAIS                                                     │
│                                                                            │
│ Parâmetros de Entrada:                                                     │
│   BBPeriod = 24                                                            │
│   BBDeviation = 2.2                                                        │
│   UseBBValidation = true                                                   │
│   BB_UpperThreshold = 0.7                                                  │
│   BB_LowerThreshold = 0.3                                                  │
│   UseADXValidation = true                                                  │
│   MinADXStrength = 20.0                                                    │
│                                                                            │
│ Validações Executadas:                                                     │
│   ✓ ValidateWithRSI()                                                      │
│   ✓ ValidateWithBollingerBands()          ❌ REMOVIDA                      │
│   ✓ ValidateWithADX()                     ❌ REMOVIDA                      │
│   ✓ ValidateWithTrend()                                                    │
│                                                                            │
└────────────────────────────────────────────────────────────────────────────┘

║ Indicadores          │ 6 (MA,RSI,    │ 5 (MA,RSI,    │ -1 indicador        ║

╟──────────────────────┼───────────────┼───────────────┼─────────────────────╢
║ Total Estados        │ 576           │ 288           │ ↓ 50% (metade)      ║
╟──────────────────────┼───────────────┼───────────────┼─────────────────────╢
║ Bins Tendência       │ ADX: 2 bins   │ MACD: 3 bins  │ Mais granular       ║
╟──────────────────────┼───────────────┼───────────────┼─────────────────────╢
║ Bins Volatilidade    │ BB: 3 bins    │ (removido)    │ ATR ainda mede vol  ║
╟──────────────────────┼───────────────┼───────────────┼─────────────────────╢
║ Validações           │ 4 funções     │ 2 funções     │ ↓ 50% mais rápido   ║
╟──────────────────────┼───────────────┼───────────────┼─────────────────────╢
║ Memória (Q-table)    │ 576×3=1728    │ 288×3=864     │ ↓ 50% memória       ║
╟──────────────────────┼───────────────┼───────────────┼─────────────────────╢
║ Aprendizado          │ Mais lento    │ Mais rápido   │ Menos estados       ║
╟──────────────────────┼───────────────┼───────────────┼─────────────────────╢
║ Complexidade         │ Alta          │ Média         │ Mais simples        ║
╚════════════════════════════════════════════════════════════════════════════╝

┌────────────────────────────────────────────────────────────────────────────┐
│ DISCRETIZAÇÃO DO MACD (3 Buckets)                                         │
├────────────────────────────────────────────────────────────────────────────┤
│                                                                            │
│   Bucket 0 (BEARISH):  Histograma < -0.0001                               │
│   ├─ MACD abaixo da linha de sinal                                        │
│   └─ Momentum de baixa                                                    │
│                                                                            │
│   Bucket 1 (NEUTRO):   -0.0001 ≤ Histograma ≤ 0.0001                     │
│   ├─ MACD próximo da linha de sinal                                       │
│   └─ Sem tendência clara                                                  │
│                                                                            │
│   Bucket 2 (BULLISH):  Histograma > 0.0001                                │
│   ├─ MACD acima da linha de sinal                                         │
│   └─ Momentum de alta                                                     │
│                                                                            │
└────────────────────────────────────────────────────────────────────────────┘
